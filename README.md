# anish8129.github.io

Personal portfolio website built with plain HTML, CSS, and JavaScript.

## Live

[anish8129.github.io](https://anish8129.github.io/)

## Content Management

All content is driven by `data.json`. Update it directly or use GitHub Actions workflows:

| Workflow | What it does |
|----------|-------------|
| **Manage Profile** | Update name, title, description, email, links, resume URL |
| **Manage Skills** | Add/remove skills and categories |
| **Manage Experience** | Add/update/delete work experience entries |
| **Manage Projects** | Add/remove projects with tech stack, enable/disable section |
| **Update Profile Image** | Replace profile photo via any image URL (Google Drive supported) |

## Local Development

python3 -m http.server 8080
